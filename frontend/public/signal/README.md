# Homepage reference assets

The public homepage recreates the user-provided screenshot of https://signal.org/.

Reference images were retrieved from Signal’s public site on 2026-10-09:

- `logo.png`: https://signal.org/assets/images/header/logo.png
- Phone mockups and feature illustrations: https://signal.org/assets/images/features/ (original filenames retained).
- `favicon.svg`: https://signal.org/assets/images/favicon/favicon.svg
- `app-logo.svg` and `app-logo-white.svg`: official logo vectors from the user-provided Signal brand assets in the `screens` folder, used in the messenger and account screens.
- Inter Regular, Medium, SemiBold, and ExtraBold: https://signal.org/assets/fonts/inter/ (original filenames retained). Inter is licensed under the SIL Open Font License; see `Inter-LICENSE.txt`.
- `encryption.png`: a static browser rendering at frame 410 of https://signal.org/animations/encryption-animation.json, matching the conversation in the supplied screenshot.

Signal’s name, logo, and artwork belong to their respective owners. This repository is an independent recreation and is not affiliated with Signal. The homepage’s claims about encryption, calling, and nonprofit operation describe the official Signal product, not this project’s local messenger. Demo limitations are stated on `/download`, `/login`, and in the project README. Official destination links retain their original ownership.
