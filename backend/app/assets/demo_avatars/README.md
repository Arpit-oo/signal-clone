# Demo profile portraits

These original, fictional portraits were generated with the built-in image_gen tool using the imagegen skill. They depict no identified real people and are independent of Signal's reference artwork. This folder contains only the optimized 512 by 512 JPEGs served at `/api/demo-avatars/{name}-v1.jpg`; high-resolution generation outputs are excluded from the submission. The nine files total less than 500 KB and require no external image requests or runtime conversion. Keep v1 assets unchanged because their URLs use immutable caching; introduce a new version for replacement pictures.

## Prompts

Shared prompt for Priya, Marcus, Sofia, Liam, Aisha, Daniel, Emma and Rahul:

```
Create a single square, photorealistic casual profile picture for {name}, a fictional adult demo account in a messaging app. {subject} Head and shoulders, looking at the camera, face centered with generous room for a circular avatar crop. Soft natural daylight, realistic skin texture, authentic everyday photo rather than a polished studio headshot. One person only. No text, no logos, no border, no collage. Output one square image.
```
